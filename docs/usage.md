# 사용 안내

## 과정 시작과 완료

새 과정에서 주제를 입력하면 학습 목표, 범위와 파트로 구성된 계획이 만들어집니다. 시작 전에 제목과 목표, 파트 내용, 학습 시간을 직접 편집하거나 AI에게 조정을 요청할 수 있습니다.

교재를 읽고 현재 파트를 직접 완료합니다. 모든 확정 파트를 마치면 기본 과정이 완료됩니다. 더 공부하고 싶은 심화 주제를 선택하면 별도 과정으로 시작하며, 자동으로 과정이 계속 늘어나지 않습니다.

퀴즈는 메모나 종이에 풀고 원하는 때 정답을 펼칩니다. 점수나 진행 통과 조건은 없습니다. 진도와 읽던 위치, 퀴즈 메모, 정답 공개 상태는 자동 저장합니다.

## 생성 준비

[Codex 인증 안내](https://developers.openai.com/codex/auth)에 따라 CLI를 설치하고 ChatGPT로 로그인합니다.

```sh
codex login
codex login status
```

앱은 `Logged in using ChatGPT` 인증을 확인합니다. 실행 파일을 찾지 못하면 **Study Swift → Settings… → Codex 실행 파일**에 경로를 입력하세요. CLI 0.160.1에서 실제 생성을 확인했습니다. 이후 CLI 변경에 따른 차이는 [호환성 절차](compatibility.md)를 따릅니다.

생성에는 구독 한도가 적용되며 API 키나 별도 유료 API로 전환하지 않습니다. 생성 취소, 시간 제한 또는 실패가 발생하면 기존 교재를 유지합니다.

## 그림과 PDF

교재에는 도식과 필요한 삽화가 포함됩니다. 원본을 표시할 수 없으면 저장된 대체 그림을 사용하고, 마지막으로 ASCII 도식을 표시합니다. **더 보기 → 원본 그림 재시도**에서 다시 준비할 수 있습니다. **그림 크게 보기**는 원본을 기본 이미지 앱에서 엽니다. 코드와 ASCII는 공백과 줄바꿈을 보존하며 폭이 부족하면 가로로 스크롤합니다.

**PDF 내보내기**는 현재 파트의 본문, 그림과 퀴즈를 저장합니다. 정답과 해설은 문제 이후의 새 페이지에서 시작합니다.

기존 교재의 `lesson.json`은 **더 보기 → 교재 가져오기**로 열 수 있습니다. 파일을 검증하고 그림을 로컬로 준비하며 AI를 호출하지 않습니다. 기존 SQLite 보관함 전체의 자동 이전은 지원하지 않습니다.

## 단축키

| 동작 | 단축키 |
|---|---|
| 새 학습 과정 | ⌘N |
| 파트 PDF 내보내기 | ⌘P |
| 본문 크게 / 작게 | ⌘+ / ⌘− |
| 기본 18pt | ⌘0 |
| 이전 / 다음 내용 | ⌘[ / ⌘] |
| 앱 설정 | ⌘, |

## 저장 위치

학습 데이터는 `~/Library/Application Support/StudySwift`의 `library.json`, `materials/`, `jobs/`에 저장합니다. `--data-dir`로 별도 폴더를 지정할 수 있습니다. 글자 크기와 테마, CLI 경로는 macOS 사용자 설정에 저장합니다. Codex 인증 파일은 기존 위치를 사용하며 앱이 복사하지 않습니다.

샘플을 별도 보관함에서 실행하려면 다음 명령을 사용합니다. 샘플은 AI를 호출하지 않습니다.

```sh
swift run StudySwift --demo --data-dir ./data/demo
```
