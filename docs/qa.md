# QA 기록

2026-10-08 검증 완료. 고정 샘플, 실패를 유도한 fixture, 실제 Codex 구독 생성 결과를 구분한다. 모든 실행은 별도 `--data-dir`를 사용했으며 기존 Study TUI 저장소·보관함·인증은 변경하지 않았다.

## 실행 환경

| 항목 | 확인한 값 |
|---|---|
| OS / CPU | macOS 27.0.1 (26A434), Apple Silicon arm64 |
| 도구 | Command Line Tools, Swift 6.4 |
| 배포 최소 타깃 | macOS 14 |
| 인증 / CLI | 기존 ChatGPT 구독 로그인, Codex CLI 0.160.1 |
| 앱 | Release, 0.1.0, ad-hoc 서명 |
| UI 캡처 | 실제 1280×850pt 창, 2560×1700 PNG |

최소 타깃 지정은 macOS 14·Intel Mac 실기기 검증을 의미하지 않는다. 개발자 인증서 서명·공증·App Store 배포는 수행하지 않았다.

## 자동 검증

실제 새 저장소에서 `swift run RunTests`를 실행해 **4개 suite, 37개 테스트가 모두 통과**했다. 앱 Release 빌드도 성공했다. CLT가 존재하지 않는 Developer 프레임워크 검색 경로에 대해 출력한 링크 경고는 빌드·실행을 막지 않았다.

| 범위 | 테스트 수 | 주요 검증 |
|---|---:|---|
| ModelTests | 18 | 버전 1 JSON, 30~45분 계획·연속 파트, 필수 내용·시각자료·출처, 중복/미참조 ID, 언어 학습 대상 문장, ASCII 제한, 순서와 무관한 명시적 완료, Markdown 코드·표·단계 |
| RepositoryTests | 5 | 메모·정답 공개·진도 재개, 손상/미지원 버전 보존, 경로 탈출·심볼릭 링크·과도한 파일 크기 거부 |
| ProcessTests | 9 | API 키 제거, 이벤트/종료 코드, 실패 이벤트, 큰 stdin, 조기 stdin 종료, 시간 제한·취소·앱 종료 시 자식 그룹 종료, 실행 경로 오류 |
| RenderingTests | 5 | SVG 실행/외부 참조 차단, 저장 ASCII 대체와 AI 미호출, 후보 전체 실패, 한글 PDF·정답 페이지 분리, PDF 실패 시 이전 파일 보존 |

프로세스 종료 테스트는 실제 로컬 fixture 자식 프로세스를 사용한다. 원격 AI 응답을 흉내 내는 fixture를 실제 서비스 성공으로 간주하지 않았다.

## 실제 Codex 구독 검증

| 경로 | 실제 수행과 결과 |
|---|---|
| 코어 생성 QA | 광합성 계획 1파트·40분, 교재 생성, 두 Mermaid 그림의 PNG 렌더링, 원자적 저장, 재개·PDF 성공 |
| 네이티브 이미지 QA | Codex 네이티브 이미지 기능으로 잎·햇빛·물·산소 삽화 PNG 생성. 파일 디코딩과 실제 그림을 확인 |
| 앱 UI 생성 QA | 새 과정에서 달의 위상 주제 입력 → 실제 계획 생성 → 네이티브 편집기로 제목 수정·저장 → 시작 → 실제 30분 교재 생성 |
| 앱 UI 시각자료 | 달의 위상 SVG를 로컬 PNG로 준비, 개념/원리/예제/요약/퀴즈 표시. 같은 종류의 여러 내용을 원리 1·2, 예제 1·2로 구분 |
| 저장 교재 재개 | `--reopen --export-saved`에서 AI 호출 없이 저장 자료로 PDF 내보내기 성공 |

코어 QA에는 이미지·계획·교재의 3개 작업 폴더, UI 생성에는 계획·교재의 2개 작업 폴더가 남았다. `lesson.json`을 앱으로 가져온 뒤에도 UI 작업 폴더는 2개로 유지되어 추가 AI 호출이 없음을 확인했다.

달 그림의 태양 방향·밝은 절반·지구 관찰 방향·삭/상현/보름/하현 위치를 검토했다. [NASA Moon Phases](https://science.nasa.gov/moon/moon-phases/)와 [Eclipses](https://science.nasa.gov/moon/eclipses/)를 참고했다. 위치 모형과 실제 눈에 보이는 원반을 구분하는 설명을 확인했으며 전체 교재의 사실 검증이나 실제 학습 시간 실험을 수행한 것은 아니다.

| 동작 | 확인 결과 |

| 읽던 위치 | 내용 탭과 스크롤을 저장하고 재실행 후 같은 위치 복원. 사이드바 숨김/표시 때 폭에 맞춰 다시 배치 |
| 퀴즈 | 고정 샘플에 메모 입력·선택 정답 공개. 재실행 후 두 상태 유지. 메모 없이도 파트 완료 가능 |
| 완료 순서 | 샘플 Part 2부터 완료 → 1/2로 유지 → Part 1 완료 → 과정 2/2 완료. 완료 과정을 다시 읽어도 완료 유지 |
| 심화 | 완료 후 별의 일생 후보 선택 시 새 과정 입력만 열리고 자동 생성하지 않음 |
| 가져오기 | 실제 광합성 JSON을 파일 대화상자로 가져와 검증·로컬 Mermaid 준비·표시. AI 호출 없음 |
| CLI 실패 | 실행 경로를 존재하지 않는 QA 경로로 바꾸고 기존 교재 재생성 → 안내 오류. 교재·선택 그림·진도 기록이 이전과 동일. 실제 CLI 경로 복원 |
| 손상 보관함 | `{broken` fixture 실행 → 오류 안내. 샘플 저장도 중지. fixture 파일 바이트 유지 |
| 자료 폴더 실패 | 보관함 위치에 디렉터리 대신 파일을 둔 fixture 실행 → 저장 경로 오류 안내, 앱이 종료되거나 충돌하지 않음 |
| PDF 저장 UI | 상단 PDF 버튼 → macOS 저장 대화상자 → 달의 위상 PDF 저장 성공. 7페이지이며 코어에서 내보낸 최종 PDF와 추출 본문이 동일 |
| 앱 이동 | 결과 폴더로 `.app`을 복사해 실행. 원본 그림 재시도로 번들의 Mermaid를 사용해 실제 PNG 생성, 대체 사유 없음. 원본과 복사본 실행 파일 SHA-256 동일 |
| 서명 | 복사한 Release `.app`의 `codesign --verify --deep --strict` 통과 |

## PDF 페이지 검토

최종 수정 후 PDFKit으로 모든 페이지를 PNG로 내보내 **31페이지 전체를 육안 검토**했다. 문제·정답 시작 페이지는 정확한 제목 행으로 검사했다. UI 저장 PDF는 달 교재와 동일한 7페이지를 추가로 확인했다.

| 자료 | 출처 | 페이지 수 | 문제 / 정답 시작 |
|---|---|---:|---|
| 인덱스 Part 1 | 고정 샘플, 실제 Mermaid 렌더링 | 5 | 4 / 5 |
| 인덱스 Part 2 | 고정 샘플, 실제 Mermaid 렌더링 | 4 | 3 / 4 |
| 긴 코드·한글·ASCII | 스트레스 fixture | 8 | 7 / 8 |
| 광합성 | 실제 Codex 생성, Mermaid | 7 | 6 / 7 |
| 달의 위상 | 실제 UI 생성, SVG | 7 | 6 / 7 |

한글 표시, 긴 코드 줄바꿈과 페이지 나눔, ASCII 고정폭, 표 셀 줄바꿈과 이어지는 페이지의 헤더, 그림과 캡션, 출처, 문제 이후의 정답 페이지를 확인했다. 검토 중 발견한 내용 제목의 페이지 끝 고립과 그림 캡션 분리를 수정한 뒤 최종 문서로 재확인했다.

## 재현 명령

```sh
swift run RunTests
swift run PackageApp --release
swift run StudyQA --data-dir ./work/local-qa --render-demo --stress-pdf --reopen
```

다음 첫 명령만 실제 구독을 사용한다. 생성 후 두 번째 명령은 저장 자료만 읽는다.

```sh
swift run StudyQA --data-dir ./work/live-qa --live --live-image
swift run StudyQA --data-dir ./work/live-qa --reopen --export-saved
```

실제 모델 출력과 페이지 수는 새 실행마다 달라질 수 있다. 긴 시간 연속 사용·대규모 보관함·VoiceOver 전체 흐름·다른 macOS/Intel 하드웨어·CLI의 다른 버전은 검증하지 않았다. 기존 SQLite 보관함 전체 자동 이전은 구현 범위에 포함하지 않는다.
