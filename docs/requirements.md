# 요구사항

기존 [study-tui](https://github.com/zzoe2346/study-tui)의 학습 개념과 비용 조건을 이어받는다. 사용자 요청에 따라 별도 저장소, Swift 전용 macOS 네이티브 앱, 실행·QA·스크린샷 README·GitHub 푸시까지 구현한다.

## 확정 요구사항

- 직접 입력한 주제를 학습한다. 소프트웨어 공학 외의 과학·역사·언어 등도 허용한다. 설명은 한국어를 기본으로 하며 언어 학습의 대상 문장·어휘는 허용한다.
- AI 학습 목표·범위·유한한 과정 초안 → 사용자 편집/조정 → 시작. 긴 설문·진단·이력서 분석은 없다.
- 파트는 30~45분이며 개념·원리·주제에 맞는 예제/활동·필수 시각자료·간단한 퀴즈·요약을 포함한다.
- 모든 확정 파트를 사용자가 완료해야 기본 과정이 완료된다. 뒤의 파트를 먼저 읽어도 앞을 자동 완료하지 않는다. 완료 후 복습은 완료 상태를 유지한다.
- 심화 후보와 이유를 제시하며, 선택할 때만 새 과정을 시작한다. 자동 무한 확장은 없다.
- 퀴즈는 메모/종이 풀이와 선택 정답 공개다. 채점·점수·강제 재시험·진행 통과 조건은 없다.
- 자료·현재 파트·내용·읽던 위치·답 메모·정답 공개를 로컬 저장하고 재개한다. 생성 실패는 기존 자료와 진행을 보존한다.
- Mermaid/SVG·필요한 생성 삽화와 저장된 ASCII 대체를 지원한다. 후보는 교재와 함께 저장하며 새 AI 호출로 자동 대체를 만들지 않는다. 원본 재시도는 사용자 선택이다.
- 화면에서 글자 크기·밝은/어두운/시스템 테마를 선택하고 설정을 유지한다. 기본은 밝은 테마와 18pt 본문이다.
- 인쇄용 PDF는 파트별이며 본문·예제·같은 선택 시각자료·퀴즈를 포함한다. 정답과 해설은 문제 이후의 별도 페이지에서 시작한다.
- 기존 ChatGPT/Codex 구독 인증으로 Codex CLI를 자식 프로세스로 호출한다. 구독 한도가 적용되며 API 키·별도 유료 API로 전환하지 않는다.
- 글로벌 Codex/Git 설정과 사용자 인증을 변경하거나 복사하지 않는다. 별도 HTTP 서버는 없다. AI 생성은 원격 서비스에 의존한다.
- 기존과 같은 Git author·한국어 Conventional Commits·Codex 공동 작성자 트레일러, 공개 저장소와 MIT 라이선스를 사용한다. 로컬 교재·인증·작업 파일은 커밋하지 않는다.

## Swift 구현 선택

- Swift 6 도구, SwiftUI/AppKit, macOS 14 이상. Swift Package Manager로 빌드하고 Swift 도구로 `.app`을 묶는다.
- Foundation Codable 모델과 원자적 JSON 보관함, 교재별 자료 폴더. 기존 SQLite 설계는 새 앱의 필수 기술 조건이 아니므로 새 앱은 별도 Python DB에 연결하지 않는다.
- AppKit/CoreText/CoreGraphics로 PDF를 생성한다. WebKit은 앱 안에서 로컬 Mermaid/SVG를 이미지로 렌더링하는 데만 사용한다. HTML 화면이나 JavaScript 애플리케이션을 만들지 않는다.
- Mermaid 11.12.2 런타임과 MIT 라이선스만 로컬로 포함한다. 시스템 글꼴을 사용한다.
- 기본 검색 cached, 설정에서 live 선택. 모델은 고정하지 않고 CLI 기본값을 사용한다. AI 작업은 동시에 하나이며 수동 취소·제한 시간을 둔다.
- 기존 `lesson.json` 가져오기는 AI 호출 없이 파일을 검증하고 표시한다. 기존 SQLite 과정 전체 자동 이전은 범위 밖이다.

## 검증 경계

실제 macOS arm64 실행, Codex 구독 생성, PDF 페이지와 UI를 확인하고 최종 결과를 [QA 기록](qa.md)에 남긴다. 생성 구조 검증은 사실 정확성이나 실제 30~45분 학습 시간 실험을 의미하지 않는다. 다른 OS·App Store 배포·개발자 인증서 서명·공증은 범위 밖이다.
